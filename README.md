# QR Code Generator

A simple QR code generator built using Node.js.

## Features
- Accepts a URL through an interactive command-line prompt.
- Generates a QR code image.
- Saves the entered URL to a text file.

## Technologies Used
- Node.js
- Inquirer
- qr-image
- npm

## How to Run

1. Clone this repository.
2. Install dependencies:

   npm install

3. Run the application:

   node index.js
